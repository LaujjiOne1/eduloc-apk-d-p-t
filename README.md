# EduLoc — Releases APK

Bienvenue dans le dépôt des versions Android d’**EduLoc**.

## Télécharger l’APK

Consultez la page [Releases](https://github.com/LaujjiOne1/eduloc-apk-d-p-t/releases) pour télécharger l’APK disponible. Ouvrez la dernière version publiée et choisissez le fichier `.apk` dans la section **Assets**.

> Si aucune version n’est publiée, la page Releases ne contiendra pas encore de fichier à télécharger.

## Installer l’application

1. Téléchargez le fichier APK depuis une release de ce dépôt.
2. Ouvrez le fichier sur votre appareil Android.
3. Si Android le demande, autorisez temporairement l’installation d’applications provenant de cette source.
4. Suivez les instructions affichées pour terminer l’installation.

N’installez que des APK provenant d’une source de confiance. Vérifiez les informations de la release avant l’installation.

## Notes de version

Chaque release devrait préciser les changements apportés, la version de l’application et, si nécessaire, les instructions de mise à jour. Consultez la description de la release pour connaître les détails de la version téléchargée.

## Signaler un problème

Si vous rencontrez un problème avec l’APK, ouvrez une [issue](https://github.com/LaujjiOne1/eduloc-apk-d-p-t/issues) et indiquez la version installée ainsi que le modèle de votre appareil et sa version d’Android.
